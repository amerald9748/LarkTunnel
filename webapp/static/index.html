🔍 典型调查流程 ① 发现异常（某柜某路线的记录不见了）→ ② 在上方关键字框输入线索 （柜号 / 批次号 / 路线，空格分隔 = 同时满足，如 BEAU6279991 YVR4）→ ③ 点击结果行展开，查看被删记录的 全部字段内容、操作人与时间 → ④ 遇到没解析出来的 opt… 值，粘到「ID 解析」框回车。 🧹 条件删除 — 字段说明 条件是一个 JSON 对象，可用键（全部可组合，同时满足才删）： q 关键字（空格=且，等同搜索框）· action（record_deleted / record_added / record_edited）· table_id（tbl 开头，表下拉框里可查）· record_id · from/to（含当天， YYYY-MM-DD 或 YYYY-MM-DD HH:MM） ⚡ 示例（点「填入」即可开始）
{"action":"record_edited"} 清掉旧策略时期的全部编辑事件
{"to":"2026-08-31"} 删除 8 月底（含）之前的所有日志
{"to":"…30 天前…"} 只保留最近 30 天（日期自动计算）
{"q":"BEAU6279991"} 清掉某个柜号的全部日志
{"action":"record_added","table_id":"tblbJiIHMwND2OGX","from":"2026-09-01","to":"2026-09-03"} 3.1 表某日期段的新增事件
{"q":"yvr4 2026-LY","action":"record_deleted"} 关键字组合 + 只删删除事件
